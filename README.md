# Tavern-SRPG

SillyTavern 战棋（SRPG）扩展。在棋盘上操作战斗，由插件计算结果，再把结果以**用户消息**的形式交给 LLM 描写。

- 自定义单位数值：HP / ATK / MATK / DEF / MDEF / AGI / MOV，另有攻击射程、攻击类型、飞行、AI 行为和技能
- 常驻特质：自定义名称和描述，组合属性加减（百分比或固定值）、阵营回合开始恢复HP（百分比或固定值）、范围内吸引AI优先攻击；提供「强壮 / 再生 / 欠揍」快捷模板，编辑时先选择一个特质
- 命中判定：由敏捷差和地形闪避决定命中率，攻击、反击、技能都可能落空
- 技能分物理伤害 / 魔法伤害 / 辅助三类，带回合冷却；可附加预设效果（攻防升降、嘲讽、中毒、眩晕、恢复 HP 等）
- 单位可以**绑定世界书条目**：描写时自动带上条目关键词以触发该条目，也可以把条目内容注入战场状态
- 自定义地形（河流、平原、峡谷……）：移动消耗、步行/飞行能否通过、减伤、闪避加成、回合回复、给 LLM 的描述
- 地形伤害：落脚扣血、阵营回合开始扣血，支持固定值＋最大 HP 百分比；自带熔岩预设，可设置是否伤害飞行单位
- 递减防御伤害公式：防御平滑减伤、技能倍率线性生效，物理和魔法分别计算，仍可选择旧公式
- 战斗手动修改：放置 / 撤除 / 移动单位、调整 HP 和数值、复活 / 重置技能、修改地形、击败场上敌人，支持撤销
- 「仅结算回合」：由内置 AI 结算，不调用 LLM、不发送消息；保留行动供稍后手动发送
- MAP攻击：从角色向上下左右延伸的直线攻击，或指定地块为中心的范围攻击；覆盖目标同时受伤，不反击，可设置友军误伤
- 后手武器：大剑 / 重武器主动普通攻击时，能回击且不是后手的目标先出手；先被击败则攻击取消
- 行动过程：我方与敌方逐格移动、攻击闪烁、伤害 / 回复数字；可调速度、关闭或随时跳过
- 交战确认：选择攻击对象后先查看命中伤害、命中率、期望伤害与反击风险，可单独战斗或立即让 LLM 描写这次交战
- 受击反应：敌人攻击我方角色时暂停，选择反击或防御；无法反击时只提供防御，防御默认额外减伤50%
- 地图编辑器：画地形、放置我方/敌方/友军单位
- **资料卡**：单位、地形、地图和战斗规则打包成资料卡，可以绑定到角色卡或群组，打开聊天时自动切换；还能写进角色卡，随卡分享
- **仅显式绑定后启用**：未绑定角色 / 群组不使用默认卡，不注入、不处理指令、不改变聊天消息显示；一张资料卡可以绑定多个角色
- 三种任务：**歼灭战**、**守城战**、**进攻战**，敌人的寻路目标随任务变化；可以设置敌人（或友军）定期增援
- 描写模式可调：是否描写移动、普通攻击、技能、敌人行动、友军行动、回合切换
- 自由输入的文字**不会改变棋盘**
- LLM 也能影响战场：担任敌方 / 友军的指挥官选择行动，或在回复中用指令让剧情改变战场（落石、撤退、援军、地形变化……），由战斗系统校验后执行
- LLM 可以读取完整战场：地图网格、每个单位的 HP / 属性 / 状态 / 技能冷却 / 位置 / 敌我距离；支持自动注入、`{{srpg}}` 宏和函数调用查询

## 安装

**推荐：** 在 SillyTavern 中打开「扩展」面板 →「安装扩展」，输入下面的地址：

```
https://github.com/DoubleOpenFreezer/Tavern-SRPG
```

**手动安装：** 下载或 `git clone` 本仓库，把整个目录放到下面任意位置，然后刷新 SillyTavern：

- `SillyTavern/data/<用户名>/extensions/Tavern-SRPG/`
- `SillyTavern/public/scripts/extensions/third-party/Tavern-SRPG/`

更新：在「扩展」面板里点「更新」，或在该目录下 `git pull`。

打开方式：点击屏幕右侧的**悬浮按钮**（♞，可以拖到任意位置）；也可以用输入框左侧的魔杖菜单 →「Tavern-SRPG 战棋」，扩展设置里的「打开战棋面板」，或输入 `/srpg`。

未绑定的聊天不会显示悬浮按钮，也不会自动打开战棋。首次使用时，请从魔杖菜单、扩展设置或 `/srpg` 手动打开「资料卡」，为当前角色绑定资料卡后再开始战斗。只选择资料卡进行编辑不会启用当前聊天。

**界面布局**
- 完整窗口可以拖动、调整大小，包含战场、资料卡、单位、地形、地图和设置。
- 点击面板右上角的「缩小为战斗小窗」按钮，只保留地图和必要操作：开始战斗、移动、攻击、技能、待机、撤销、结束回合和发送行动。
- 小窗高度随内容变化，可拖到方便的位置，不会挤压聊天区域；点击「恢复完整窗口」返回之前的编辑页和窗口尺寸。
- 小窗中的「处理剧情提议」会打开完整战场页，查看并确认 LLM 提议的变化。
- ✕ 收起窗口，再点悬浮按钮打开。手机上完整窗口全屏，小窗仍保持紧凑。

## 使用流程

0. **资料卡**页：选择或新建一张资料卡，并把它绑定到当前角色（见下方「资料卡」）。下面几步编辑的都是正在使用的资料卡。
1. **地形**页：按需修改或新增地形。自带平原、森林、山地、河流、峡谷、桥梁、沙地、堡垒、城墙。
2. **单位**页：创建我方、敌方、友军单位，填写数值和技能；在「世界书绑定」里选择世界书和条目。
3. **地图**页：新建地图，用「画地形」绘制（可按住拖动），用「放置单位」摆放单位（同一单位可以放多个，自动编号 A、B、C）；在地图下方选择任务类型，用「增援点」工具或「添加增援」设置增援。
4. 打开一个聊天，在**战场**页选择地图 →「开始战斗」。战斗进度保存在当前聊天的元数据里，每个聊天互不影响。
5. 在棋盘上操作：
   - 点击我方单位 → 蓝色是可移动范围，红色是移动后可攻击的范围
   - 点击蓝色格子移动（或点「原地行动」）→ 选择「攻击」/ 技能 /「待机」/「撤销移动」
   - 攻击：点击闪烁的敌人；悬停时显示预计伤害和反击
   - 技能：点击技能后选择目标格，范围技能会以黄色显示影响区域
   - 右键取消选择；顶部「撤销」可撤回本回合的操作
6. 「结束回合」→ 敌方与友军由 AI 行动 → 自动整理本回合的全部结果，按设置预览或直接发送。也可以随时点「预览并发送」只发送已经发生的行动。
7. 「补充要求」输入框里的文字会作为【用户补充要求】附在消息末尾。开启「附带主输入框中的文字」后，主输入框里已有的文字也会一起带上。

**快速结算与手动修改**

- 点击「仅结算回合」可跳过叙事请求。即使启用了 LLM 指挥官，该次也使用内置 AI；待发送行动会累积，需要时再点击发送。也可以在设置中关闭「结束回合时自动整理发送」。
- 完整窗口和战斗小窗都有「手动修改」入口。开启后，选择工具并点击棋盘，即可放置、撤除、移动单位或替换地形；选择单位后可调整 HP、最大 HP、攻击、防御、敏捷、移动、射程、阵营、飞行和行动状态。
- 「满血 / 重置行动技能」可复活所选单位、解除状态、恢复技能次数与冷却；「击败场上全部敌人」可清理残局，地图中的后续增援仍然有效。
- 修改只影响当前战斗，可用「撤销」恢复；胜负会重新判定，下一次发送行动时会包含修改说明。手动移动和放置不触发落脚伤害。

**熔岩与伤害公式**

- 在「地形」页点击「添加熔岩」，旧资料卡也能添加。预设落脚扣 5 HP，所属阵营回合开始扣最大 HP 的 10%；飞行单位默认免疫。地形编辑器可以修改固定伤害、百分比伤害及飞行免疫。
- 落脚伤害只计算移动终点，沿途格子不扣血；原地行动不重复触发。地形伤害可致死、不受防御减免；回合伤害先于地形回复结算。
- 新默认伤害为 `攻击 × 威力% × 防御基准 ÷（防御基准＋防御）`，基准默认 12：防御 12 减伤 50%，防御 24 减伤约 67%。物理使用 ATK/DEF，魔法使用 MATK/MDEF，再计算地形、随机浮动和最低伤害。
- 首次升级会将资料卡中的旧默认减法公式切换为递减防御；比例公式保留。可在「设置 → 战斗规则」调整防御基准或切回旧公式。

**MAP攻击、后手武器与行动过程**

- 在「单位 → 技能」中选择一个伤害技能，将「攻击方式」设为「MAP：直线路径攻击」或「MAP：指定地块范围攻击」。物理 / 魔法类型仍决定使用的攻击、防御属性。
- 直线模式设置「直线长度」，例如 3 格；战斗中点击角色上下左右方向上的任一覆盖格，攻击从角色向该方向延伸的整条路径。路径穿过单位和地形，在地图边界停止，不支持斜线。
- 地块范围模式设置施放射程和范围半径；选择射程内任意地块，攻击中心周围按格子距离计算的菱形区域。半径 1 包含中心及上下左右；可以选择空地，范围内没有目标时也消耗技能。
- MAP攻击不触发反击，也不触发后手交换；命中、威力、冷却、次数仍遵守技能规则。默认影响敌我全部单位和建筑，但不伤害施法者；「MAP作用对象」可改为仅敌方。悬停时显示整片区域及目标伤害预览，敌方 AI 会计入误伤风险。
- 在「单位 → 普通攻击顺序」选择「后手：大剑 / 重武器」，并可填写武器名称。主动普通攻击时，如果目标能回击、没有眩晕且不是后手角色，则目标先攻一次，自己存活后再攻击；不再追加一次普通反击。双方都为后手时由主动方先攻；目标是建筑或无法回击时也由主动方先攻。关闭普通反击不取消后手先攻规则。
- 我方行动、敌方 / 友军回合、LLM 指挥官行动和「仅结算回合」都会显示过程。棋盘上逐格播放移动、显示先攻 / 攻击 / 反击顺序、闪烁覆盖区域、显示伤害或回复数字。过程不重复判定伤害，期间锁定操作；「跳过过程」直接显示已结算结果。
- 「设置 → 界面」可关闭「显示移动和攻击过程」或调整过程速度。切换聊天会停止旧战斗的过程，避免影响新聊天。

**交战细节与反击 / 防御**

- 我方选择普通攻击目标或伤害技能的目标地块后，先出现「战斗确认」。显示命中时伤害、命中率、期望伤害、对方存活后反击的伤害与命中率；后手武器会标明对方先攻的风险。取消不会结算伤害，也不消耗此次攻击。
- 「战斗」只结算；「战斗并生成描写」结算并立即发送本次交战结果，触发 LLM 回复，不受全局发送预览模式影响。只清除本次已发送事件，之前的未发送行动继续保留。
- 期望伤害是忽略随机浮动的近似值，按命中伤害×命中概率估算，并计入先被击败或目标被击败导致不能出手的风险；确认后才执行实际随机判定。
- 敌方被攻击时默认选择可用的反击，不能反击时防御。普通伤害技能也可以被反击，MAP不能被反击。建筑无法主动防御或反击，不享受角色的额外防御减伤。
- 敌方移动到攻击位置后、扣血前，会暂停让受攻击的我方角色选择「反击」或「防御」。反击受射程、眩晕、普通反击设置与 MAP 限制；不能反击时只显示「防御」。防御放弃反击并降低本次伤害，默认减伤50%，仍受最低伤害规则约束。
- 多目标技能为每个我方目标分别选择反应，然后一并结算伤害；选择反击的存活目标依次回击，施法者倒下后不再继续反击。
- 「设置 → 战斗规则」可调整防御减伤比例；「设置 → 界面」可关闭受击手动选择，自动采用可用的反击，否则防御。静默回合也遵守受击选择，但不会请求 LLM。
- 「取消本次回合」会恢复结束回合前的棋盘；关闭窗口会取消正在等待的反应，切换聊天不会把旧战斗结算到新聊天。

如果直接在聊天输入框打字发送，棋盘不会有任何变化，LLM 只会做叙事描写；注入的战场状态会告诉它当前的 HP 和位置。

发送到聊天中的战斗信息默认显示为折叠的「战斗记录」卡片，点击标题展开 / 收起。这里只改变聊天显示，LLM 仍然读取完整信息；编辑、复制消息时也保留原文。重新打开聊天后，已有的战斗记录也会自动折叠。

## 发给 LLM 的消息示例

```
【SRPG 战斗系统】以下行动结果已由战斗系统计算完成，请据此生动地描写战斗过程。……
〔战场：河畔之战｜第 1–2 回合〕

【需要描写的行动】
· 骑士〈罗兰〉 从 (2,4)平原 移动到 (7,4)桥梁。
· 骑士〈罗兰〉 对 哥布林A 发动物理普通攻击，造成 9 点伤害（哥布林A HP 18→9）；哥布林A 反击，造成 1 点物理伤害（骑士 HP 32→31）。
—— 第 1 回合 · 敌方阶段 ——
· 哥布林弓手 对 骑士〈罗兰〉 发动物理普通攻击，造成 1 点伤害（骑士 HP 31→30）。

【背景信息（无需详细描写，一笔带过或略过即可）】
· 哥布林B 从 (9,6)平原 移动到 (7,5)桥梁。

【用户补充要求】
着重描写罗兰守桥时的心理
```

`〈罗兰〉` 是绑定世界书条目的第一个关键词，用来触发该条目。

## 资料卡

资料卡是一套完整的游戏内容：**单位、地形、地图、战斗规则**。不同的角色卡可以玩完全不同的战役。描写模式、发送方式、LLM 相关设置和界面设置属于全局设置，不在资料卡里。

- **切换**：在「资料卡」页点「使用」。「单位」「地形」「地图」页和设置里的战斗规则，编辑的都是正在使用的资料卡，页面顶部会显示资料卡名称。
- **绑定到角色卡 / 群组**：打开一个聊天，在「资料卡」页上方选择「这个角色使用的资料卡」。只有有效的显式绑定才启用战棋；未绑定聊天不会使用默认资料卡。群组需要单独绑定，不继承成员的绑定。
- **绑定多个角色卡**：在资料卡页选择要编辑的资料卡，展开「为『…』绑定多个角色卡」，勾选需要的角色。一个资料卡可绑定多个角色；单位、地图、规则共用资料卡，各聊天的战斗进度独立保存。取消勾选一个角色不会解除其他角色的绑定。
- **解除绑定**：选择「不绑定（停用战棋，不影响聊天）」后立即停止提示词注入、宏 / 工具查询、指令处理和消息折叠，隐藏悬浮按钮并收起窗口；旧战斗进度保留，重新绑定同一张资料卡后可以继续。绑定到另一张资料卡时不会读取旧资料卡的战斗。
- **写入角色卡**：点「把『…』写入角色卡」，资料卡会保存在角色卡的扩展数据（`data.extensions.tavern_srpg`）里，导出角色卡 PNG / JSON 时一起带上。导入者需手动打开资料卡页导入并绑定，或选择已存在的资料卡进行绑定；仅打开附带资料卡的角色不会自动弹窗、导入或启用。修改资料卡后，可以点「更新角色卡中的…」同步。
- **新建 / 复制 / 导出 / 导入 / 删除**：都在资料卡列表里。导出的单张资料卡是 `tavern-srpg-profile` 格式的 JSON；导入同 ID 的资料卡时会作为副本加入。设置页的「导出全部」包含所有资料卡和全局设置。
- 进行中的战斗使用开战时的数据副本，切换资料卡不会影响正在进行的战斗。
- 从旧版本升级时，原来的单位、地形、地图和规则会自动打包成「我的资料卡」，并额外附上一张内置示例资料卡。

## LLM 读取战场

为了让 LLM 的描写和棋盘对得上，插件会把战场整理成一份文档。下面是一个例子（有删减）：

```
[Tavern-SRPG 战场状态｜死守城门｜第 2 回合 · 我方阶段]
任务：守城战：敌人会直奔「城门」，保护它不被摧毁，坚守到第 5 回合结束（还剩 4 回合）。
```

**三种读取方式**（设置页「LLM 读取战场」，可以同时使用）：

1. **自动注入**：每次生成时附上。可以选择注入位置（聊天记录中按深度 / 主提示词之前 / 之后）、深度、身份（System / User / Assistant），以及包含哪些部分：地图网格、地形图例、单位属性、技能与冷却、敌我距离、绑定的世界书条目内容、最近 N 条战斗记录。
2. **宏**：在系统提示词、角色卡、世界书、作者注释里手动放置。没有战斗时宏为空。

   | 宏 | 内容 |
   | --- | --- |
   | `{{srpg}}` | 完整战场信息（与自动注入相同） |
   | `{{srpg_mission}}` | 回合、阶段、任务与增援预告 |
   | `{{srpg_map}}` | 地图网格与地形图例 |
   | `{{srpg_units}}` | 所有单位的 HP、位置、属性、状态、技能 |
   | `{{srpg_log}}` | 最近的战斗记录 |
   | `{{srpg_turn}}` | 当前回合数 |

3. **函数调用**（默认关闭）：注册只读工具 `SRPG_GetBattleState`，LLM 需要时自己查询全部信息、任务、地图、所有单位、某个单位（按名字、别名或 P1 / E2 编号查），或者最近战况。需要支持函数调用的 Chat Completion 接口，并在 AI 响应配置中开启「启用函数调用」；只在战斗进行中注册。

**让两边对上号**：单位编辑器里有「故事中的名字 / 别名」，用来填 LLM 在故事里对这个单位的称呼（逗号分隔，可以写 `{{user}}`、`{{char}}`）。别名会和绑定的世界书关键词一起写进战场信息（“又名”），发送战斗描写时也会带上第一个别名，例如 `骑士〈罗兰〉`。每个单位还有固定编号（P＝我方、A＝友军、E＝敌方），地图网格、距离描述和工具查询都用这个编号。

战场页顶部的 👁 按钮和设置页的「查看 LLM 看到的内容」，可以直接看到 LLM 收到的完整文本。

## LLM 影响战场

LLM 不会直接改数值：它要么从战斗系统列出的合法行动里做选择，要么写出指令，由战斗系统校验后再执行。两种方式都在设置页「LLM 影响战场」中开启，默认关闭。

### ① LLM 指挥官

勾选「指挥敌方」或「指挥友军」后，结束回合时：

1. 战斗系统为该阵营每个单位列出最多 N 个合法行动，例如：「移动到 (8,4) 后普通攻击 骑士[P1]（命中 81%，伤害约 9）」「使用【毒箭】作用于 法师[P2]」「向 城门[P1] 前进」「原地待命」。
2. 一次后台生成（带角色卡、聊天记录和战场信息，不会出现在聊天里），让 LLM 结合剧情和角色性格为每个单位选一个，可以附一句意图：
   ```
   E1: 1 | 为同伴报仇，冲向最近的人类
   E2: 3
   ```
3. 系统按顺序执行。前面的单位行动后，后面的选择可能已经失效（目标倒下、格子被占），这时以及 LLM 没给出选择、写了 0 时，交给内置 AI。
4. 意图会写进战斗描写：`哥布林A 从 (10,4)平原 移动到 (5,4)平原（意图：为同伴报仇，冲向最近的人类）。`

等待期间棋盘会锁定；如果中途切换了聊天，这次敌方回合不会结算。

### ② 剧情指令

勾选「启用剧情指令」后，注入的战场信息末尾会附上指令写法。剧情改变战场时，LLM 在回复最后写：

```
<srpg>
damage E1 5 被落石砸中
move E2 6 5 被冲击波击退
status P1 atk_up 30 2 受到鼓舞
retreat E3 吓得落荒而逃
</srpg>
```

| 指令 | 写法 | 说明 |
| --- | --- | --- |
| 造成伤害 | `damage <单位> <数值> [原因]` | 受「HP 变化上限」限制，默认不能直接击败（最多扣到 1） |
| 回复 HP | `heal <单位> <数值> [原因]` | 同样受上限限制 |
| 附加状态 | `status <单位> <效果> [数值] [回合] [原因]` | 只能用预设效果（中英文名都可以），按回合计时 |
| 解除状态 | `unstatus <单位> <效果\|all> [原因]` | |
| 强制移动 | `move <单位> <x> <y> [原因]` | 目标格必须空着、该单位能站上去 |
| 撤离战场 | `retreat <单位> [原因]` | 离开战场但不算被击败 |
| 新单位登场 | `spawn <单位类型名> <x> <y> [原因]` | 只能是「单位」页里定义过的单位 |
| 改变地形 | `terrain <x> <y> <地形名> [原因]` | 只能是定义过的地形 |
| 结束战斗 | `end <victory\|defeat> [原因]` | 默认不允许 |

- 单位可以写编号（P1、E2）、名字或别名；指令也接受中文（伤害、治疗、状态、移动、撤退、增援、地形……）。
- **确认模式**（默认）：提议会列在战场页上方，逐条显示预演结果，无效的会标出原因；勾选后点「应用」。**自动模式**：收到就应用，无效的指令会提示。
- 指令块默认会从聊天消息中移除，只留下正文。
- 应用后的变化记入战斗记录（`【剧情】…`），不会再作为“需要描写的行动”发给 LLM，因为 LLM 已经写过了。
- **重新生成 / 滑动 / 删除**这条回复时，它造成的改动会自动撤回；如果之后棋盘又有别的改动，就不会自动撤回，只会提示（可以用「撤销」）。滑回之前的旧回复时，不会重新应用旧回复的指令。
- 每类指令都可以单独关闭，HP 变化上限、能否直接击败也可以调整。

## 任务

| 任务 | 胜利 | 失败 | 敌人 AI（主动出击） |
| --- | --- | --- | --- |
| 歼灭战 | 击败所有敌人，且不再有后续增援 | 我方全灭；或超过回合限制 | 按距离从近到远，攻击最近的能打到的角色；打不到就向最近的角色前进 |
| 守城战 | 坚守到指定回合结束；或击退所有敌人（含增援） | 任意一个我方/友军「★ 关键目标」被摧毁；或我方全灭 | 无视角色，朝守卫目标前进并攻击它；被挡住时攻击挡路的角色 |
| 进攻战 | 摧毁所有敌方「★ 关键目标」（敌人不必全灭） | 我方全灭；或超过回合限制 | 同歼灭战，守在目标附近的敌人建议设为「原地迎击」或「固守不动」 |

- **关键目标**：在单位页勾选「★ 关键目标」。它可以是角色（例如要保护的王子、要击杀的首领），也可以是**建筑 / 目标物**（类型选「建筑 / 目标物」，只有 HP / DEF / MDEF，不会行动、不会反击，例如城门、魔法水晶、旗帜）。
- **增援**：每个增援波次设置单位、出现位置、每次数量、首次出现回合、间隔回合（0＝只出现一次）、最多次数（0＝无限）。增援在该回合敌方/友军阶段结束时出现，下一回合才会行动；出现点被占据时会在附近 3 格内找空位。棋盘上红色虚线 ⚑ 是增援出现点，本回合结束就会出现的会闪烁。增援点也可以用于友军（单位阵营决定增援属于哪一方）。
- 开战前会检查任务设置：守城战必须有我方关键目标，进攻战必须有敌方关键目标，歼灭战不能有无限次的敌方增援。
- 当前任务、剩余回合和增援预告会写进注入的战场状态，任务开始时还会作为第一条行动发给 LLM。
- 自带三张示例地图：「河畔之战」（歼灭）、「死守城门」（守城，5 回合，每 2 回合 2 只哥布林增援）、「破坏水晶」（进攻，第 2、5 回合增援）。

## 技能与效果

**技能类型**

| 类型 | 作用对象 | 说明 |
| --- | --- | --- |
| 物理伤害 | 敌方 | `ATK × 威力%` 对 DEF 计算伤害，可附加效果（命中且未被击败的目标获得） |
| 魔法伤害 | 敌方 | `MATK × 威力%` 对 MDEF 计算伤害，可附加效果 |
| 辅助 | 友方（含自己）/ 敌方 / 仅自己 | 不造成伤害，只施加效果；「仅自己」的技能点击后立即释放 |

每个技能可以设置：射程、范围半径、命中修正（±%）、必中、**冷却回合**（N＝每 N 回合可用一次，0 或 1＝每回合可用）、每场战斗的使用次数（0＝无限）。冷却在使用者阵营的阶段开始时减少，冷却中的技能按钮会显示「第几回合可用」。

**预设效果**：效果类型是固定的预设，不能新建；编辑技能时只能从下面选择，再调整数值和持续回合。

| 分组 | 效果 | 可调数值 | 说明 |
| --- | --- | --- | --- |
| 立即 | 恢复HP | MATK 的百分比 | 立即恢复 `施法者MATK × 数值%` |
| 立即 | 恢复HP（按比例） | 最大 HP 的百分比 | 立即恢复 `目标最大HP × 数值%` |
| 立即 | 驱散减益 | — | 移除目标身上所有减益 |
| 增益 | 攻击力 / 魔攻 / 防御力 / 魔防上升 | 百分比 | 属性按百分比提高 |
| 增益 | 敏捷上升 | 百分比 | 提高命中与闪避 |
| 增益 | 移动力上升 | 格数 | 移动力增加固定值 |
| 增益 | 持续恢复 | 最大 HP 的百分比 | 自己阵营的阶段开始时恢复 |
| 增益 | 嘲讽 | 影响范围（0＝全图） | 范围内的敌人只能攻击带嘲讽的单位，AI 会朝它前进；我方被敌人嘲讽时同样只能攻击嘲讽者 |
| 减益 | 攻击力 / 魔攻 / 防御力 / 魔防下降 | 百分比 | 属性按百分比降低 |
| 减益 | 敏捷下降 | 百分比 | 降低命中与闪避 |
| 减益 | 移动力下降 | 格数 | 移动力减少固定值 |
| 减益 | 中毒 | 最大 HP 的百分比 | 自己阵营的阶段开始时损失生命，最多降到 1，不会因中毒倒下 |
| 减益 | 眩晕 | — | 无法行动 |

- 持续效果的回合数在**施法者阵营**的阶段开始时减 1，归零即结束。所以给同伴加持续 1 回合的防御，会覆盖接下来的整个敌方阶段；敌人给你上的减益，也会持续到你自己的下一个阶段。
- 同一种效果再次施加时会刷新为新的数值和回合数，不会叠加。
- 单位卡片里，受影响的属性会变成绿色或红色，下方列出状态和剩余回合；棋子左上角有状态标记。注入给 LLM 的战场状态里也会写明每个单位身上的效果。
- AI 会比较「攻击」和「辅助技能」的价值：同伴 HP 低于 70% 时治疗，敌人逼近时给同伴加增益或自己嘲讽，也会给敌人上减益。估值时按命中率折算期望伤害，所以 AI 会优先打容易命中的目标，不会去打命中率 0% 的目标。
- 旧版的「治疗」技能会自动转换成「辅助·友方 + 恢复HP」，原来的威力变成恢复数值。

## 规则

| 项目 | 计算 |
| --- | --- |
| 物理伤害 | 减法：`ATK×威力% − DEF`；比例：`a²/(a+DEF)`，a = ATK×威力% |
| 魔法伤害 | 同上，改用 MATK / MDEF |
| 命中率 | `基础命中 + (攻方AGI − 守方AGI) × 系数 + 技能命中修正 − 守方地形闪避`，限制在 0–100%。默认基础 90%、系数 3% |
| 命中判定 | 普通攻击、反击、伤害技能、对敌方的辅助技能（减益）会判定；范围技能对每个目标分别判定。对友方的技能、攻击建筑物、「必中」技能一定命中。设置里可以关闭命中判定 |
| 地形减伤 | 伤害 × (1 − 防守方所在地形的减伤%) |
| 浮动 | 伤害 × (1 ± 浮动%)，四舍五入，至少为「最低伤害」 |
| 增益 / 减益 | 先按百分比修正，再加减固定值，四舍五入，最低为 0 |
| 反击 | 只有普通攻击会触发；防守方存活且攻击者在其射程内时反击 |
| 移动 | 消耗 = 地形移动消耗；不能穿过敌人；可以穿过友方但不能停在友方格子上；飞行单位每格消耗 1，只受「飞行可通过」限制 |
| 回合 | 我方 → 敌方（AI）→ 友军（AI）→ 下一回合。阶段开始时，站在回复地形上的单位会恢复 HP |
| 胜负 | 见上方「任务」 |

AI 行为（每个敌方 / 友军单位单独设置）：

- **主动出击**：按任务寻找目标（见上表；被嘲讽时只找嘲讽者），绕开障碍前进；与辅助技能比较后选择价值更高的行动
- **原地迎击**：只攻击本回合移动后能打到的目标，打不到就不动
- **固守不动**：不移动，只攻击射程内的目标

## 设置项

- **描写模式**：分别开关移动、普通攻击、技能、敌人行动、友军行动、回合切换、增援出现、状态变化（中毒 / 持续恢复 / 眩晕 / 效果结束）。关闭的项目可以作为「背景信息」一句话带过，也可以完全省略。
- **发送方式**：弹出预览（可编辑）/ 直接发送 / 只填入输入框；结束回合后是否自动整理；可自定义消息开头的指令。
- **战斗规则**：伤害公式、浮动、最低伤害、反击开关。
- **LLM 读取战场**：自动注入（位置、深度、身份、包含的部分）、宏、函数调用工具，详见上方「LLM 读取战场」。注入内容允许世界书扫描，所以写在战场信息里的单位名和别名也能触发世界书条目。
- **界面**：面板位置（停靠在右侧 / 自由浮动）、停靠宽度、格子大小上限、是否显示悬浮按钮、停靠时是否让聊天区域让出位置。
- **导入 / 导出**：导出全部资料卡和全局设置；导入时可以选择覆盖同 ID 的资料卡或作为副本导入，也能读取旧版本的导出文件。「恢复默认设置」只重置全局设置，不影响资料卡。

## 已知限制

- 战斗状态不会随 swipe / 重新生成 / 删除消息回滚。需要回退时，请在发送前使用「撤销」。
- 战斗开始时会复制一份单位数值和地形，战斗中修改定义不影响正在进行的战斗（世界书绑定除外，它会同步过去）。
- 地图最大 40×40。

## 单位特质

在「单位 → 特质」中选择已有特质或创建新特质，然后填写名称、描述并添加多个效果。例如「强壮」配置 ATK +10%，「再生」配置每次自己阵营回合开始恢复最大HP的10%，「欠揍」配置3格内敌人优先攻击自己。一个特质可以同时包含这三种效果，一个单位也可以拥有多个特质。

特质不消耗行动、不会过期、不能被驱散；与技能施加的临时状态叠加。百分比属性修正相加后作用于基础数值，再加固定修正，最终取整；回复HP不会超过上限，也不会复活。恢复在地形伤害和地形回复之后、临时状态结算之前发生。吸引范围使用曼哈顿距离，以敌人阵营阶段开始的位置判断；0代表全图。它影响AI的目标优先级，不限制玩家选择攻击对象，无法攻击吸引者时可以攻击其他目标；技能嘲讽的强制规则仍优先。LLM指挥官也会获得优先目标提示。

描述会与实际效果一起提供给LLM用于描写；描述本身不执行规则，请用效果组合配置数值行为。特质随资料卡保存、导出和分享，进入战斗或新摆放/增援时复制到单位；编辑资料卡不改变已经在场的单位。旧资料卡和已有战斗无需迁移，默认为没有特质。
